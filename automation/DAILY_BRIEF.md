## Formato JSON
Conservare schemaVersion 1 e tutti i campi richiesti dal validatore. `id` univoco per l'edizione; `mode: live`; `editionDate` ISO YYYY-MM-DD di oggi a Roma; `generatedAt` con ora reale e fuso; `timezone: Europe/Rome`; `scheduledFor` di oggi alle 07:30 con offset corretto (ora solare/legale).
`essentialIds` e `leadIds` contengono 5 id validi; `compactIds` contiene almeno 35 id diversi dalle principali. Ogni articolo ha id stabile, categoria ammessa, status verified, title, summary, body (array di paragrafi), publishedAt reale, eventuale eventDate, verifiedAt reale, source con name, url HTTPS diretto, access free, accessCheckedAt, dateEvidence ed evidenza della verifica. `reviewedBy` deve dire "Verifica automatizzata cloud" e non simulare revisione umana. Se una fonte è una pagina evento senza data editoriale, dichiarare dateKind event e rappresentare esplicitamente il limite.
